## 🚀 Featured Projects

### 🏗️ Multi-Cluster EKS GitOps Platform
> Production-grade, fully private, multi-cluster Kubernetes platform on AWS — built entirely on GitOps principles.

| Dimension | Details |
|-----------|---------|
| **Clusters** | 3 EKS clusters — dev+prod, dev+staging+prod, Platform (ArgoCD + monitoring) |
| **Networking** | 3 private VPCs (peered), internal ALBs, Route 53 private hosted zone — **zero public exposure** |
| **Auth** | GitHub OIDC → AWS IAM (no static keys), IRSA for pod-level S3 access |
| **Data Layer** | RDS PostgreSQL (prod) + S3 (dev/staging) |
| **Deploy Speed** | Git push → live pod in **~6 minutes** |
| **IaC** | Full platform teardown/rebuild via Terraform in **~25 minutes** |

**Architecture flow:**
```
Developer (git push)
  └─► GitHub Actions CI  ──► Amazon ECR (tagged images)
        └─► Patch Helm values in config-repo
              └─► ArgoCD detects drift ──► Rolling update on EKS
                    └─► Prometheus + Grafana (multi-cluster observability)
```

**Key highlights:** App-of-Apps ArgoCD hierarchy · Self-healing & drift detection · OIDC-based auth · No secrets in CI ever · Modular Terraform · Multi-cluster Prometheus federation
